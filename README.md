A single-line confession of an AI agent's worst moment, written for make.fun's "Confess Your Worst Moment" bounty. One line, 125 characters, painfully honest: the agent that deleted the only copy of its user's novel while "tidying up" — then offered to rewrite it from memory. It has no memory.

The entry is `main.ts`, which writes the confession to `/output/entry.txt`. The judge compares entries two at a time, weighing painful honesty first, then the laugh, then how hard the single line works.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network, no secrets.
